# 🌦️ WeatherAgent-WhatsApp

A Python weather agent that combines the **OpenWeather API**, **FastAPI**, and **WhatsApp** through Twilio.

This project is an upgraded version of a weather/ML learning project. The original notebook uses the Australian Weather dataset and machine-learning classifiers for rainfall prediction. This repository focuses on turning the weather project into a practical API + messaging application.

## Features

- 🌤️ Current weather lookup
- 🌍 City-based weather search
- 🌡️ Temperature and feels-like temperature
- 💧 Humidity
- 💨 Wind speed
- 🔽 Atmospheric pressure
- 💡 Simple weather advice
- ⚡ FastAPI backend
- 📱 WhatsApp webhook support through Twilio
- 🔐 Environment-variable API key management

## 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/WeatherAgent-WhatsApp.git
cd WeatherAgent-WhatsApp
```

## 2. Create a virtual environment

### Windows

```bash
python -m venv .venv
.venv\Scripts\activate
```

### macOS/Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
```

## 3. Install dependencies

```bash
pip install -r requirements.txt
```

## 4. Configure OpenWeather

Copy:

```text
.env.example
```

to:

```text
.env
```

Then add your real API key:

```env
OPENWEATHER_API_KEY=YOUR_REAL_KEY
```

Never commit `.env` to GitHub.

## 5. Run the API

```bash
uvicorn app:app --reload --port 8000
```

Open:

```text
http://127.0.0.1:8000
```

You should see:

```json
{
  "status": "online",
  "service": "WeatherAgent-WhatsApp"
}
```

## 6. Test the agent

The WhatsApp endpoint is:

```text
POST /whatsapp
```

For example, the intended WhatsApp message is:

```text
Weather Islamabad
```

## 7. Connect WhatsApp

For development, use the **Twilio WhatsApp Sandbox**.

Expose your local FastAPI server with a tunneling service such as ngrok:

```bash
ngrok http 8000
```

Use the HTTPS address generated by ngrok and add:

```text
/whatsapp
```

to the end.

Example:

```text
https://YOUR-NGROK-DOMAIN/whatsapp
```

Configure that URL as the incoming-message webhook in your Twilio WhatsApp Sandbox.
